Connect to Your WooCommerce Store

Enter your WooCommerce REST API credentials to connect and export your store data.

Your WooCommerce store URL (include https://)
  1. Log in to your WordPress admin panel
  2. Go to WooCommerce > Settings > Advanced > REST API
  3. Click "Add key"
  4. Enter a description (e.g., "HTML5 Converter")
  5. Select a user with admin privileges
  6. Set Permissions to "Read"
  7. Click "Generate API key"
  8. Copy the Consumer Key and Consumer Secret
