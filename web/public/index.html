Store Converter

Convert your e-commerce store to a blazing-fast HTML5 static site. Support for multiple platforms with a simple embeddable widget.

WooCommerce Shopify Wix Squarespace

Integration Guide

Easily embed the store converter into your AI website creator or any web application.

Quick Embed

Add the converter to any page with just a few lines of code:

<!-- 1. Add a container element --> <div id="store-converter"></div> <!-- 2. Include the embed script --> <script src="http://localhost:3002/embed.js"></script> <!-- 3. Initialize the widget --> <script> StoreConverter.init('#store-converter', { apiEndpoint: 'http://localhost:3002/api', theme: 'light', primaryColor: '#2563eb', showPlatforms: ['woocommerce', 'shopify', 'wix', 'squarespace'], onComplete: (result) => { console.log('Conversion complete!', result); } }); </script>

JavaScript SDK

Use the SDK for programmatic control:

// Import or use global StoreConverter const converter = StoreConverter.init('#widget', { apiEndpoint: 'https://your-api.com/api', onStart: (config) => { console.log('Starting conversion...', config); }, onProgress: (data) => { console.log(`Progress: ${data.progress}%`); }, onComplete: (result) => { // Handle completion const downloadUrl = `/api/download/${result.conversionId}`; window.location.href = downloadUrl; }, onError: (error) => { console.error('Conversion failed:', error); } }); // Or convert programmatically without UI const result = await StoreConverter.convert( 'https://your-api.com/api', { platform: 'shopify', shopDomain: 'store.myshopify.com', accessToken: 'shpat_xxx', siteName: 'My Store' } );

REST API

Direct API access for backend integration:

# Get supported platforms GET /api/platforms # Test connection POST /api/test-connection { "platform": "woocommerce", "siteUrl": "https://store.com", "consumerKey": "ck_xxx", "consumerSecret": "cs_xxx" } # Start conversion POST /api/convert { "platform": "shopify", "shopDomain": "store.myshopify.com", "accessToken": "shpat_xxx", "siteName": "My Store", "primaryColor": "#2563eb" } # Response: { "conversionId": "uuid" } # Stream progress (SSE) GET /api/progress/:conversionId # Download result GET /api/download/:conversionId # Preview result GET /api/preview/:conversionId
